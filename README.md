# S Power PL50

Полный статический сайт.

## Загрузка на GitHub
Распакуйте архив и загрузите его содержимое в корень репозитория spower.
index.html должен находиться в корне, папка assets должна оставаться рядом.
Видео и изображения включены в архив.

## GitHub Pages
В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root).

## Редактирование
index.html — тексты и контакты.
style.css — оформление.
app.js — видеоплееры и форма.
assets/ — видео и изображения.

Форма подготавливает письмо на spower@maspel.ru в почтовой программе посетителя. Автоматическая отправка и CRM пока не подключены.

Для Метрики добавьте код счётчика и window.SPOWER_METRIKA_ID. Цели: video_play и kp_email_prepare (подготовка письма).
